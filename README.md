# Algo Rich - Landing Page

A modern, professional landing page for **Algo Rich**, a structured programming education platform specializing in Python and Data Structures & Algorithms (DSA).

## About

Algo Rich helps programmers master Python and DSA through systematic, structured learning—not random problem-solving. The landing page showcases the platform's value proposition and learning approach.

## Tech Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS v4** - Modern, utility-first styling
- **Framer Motion** - Smooth animations and interactions
- **Inter Font** - Modern sans-serif typography
